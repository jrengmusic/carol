Take over an interrupted session on this repository.

1. Load the `takeover-protocol` skill.
2. Follow its steps in exact order using any argument ARCHITECT passed (`$ARGUMENTS`).
3. Reconcile the prior transcript tail against the working tree and repository docs.
4. Present the `TAKEOVER:` brief and wait for ARCHITECT's go-ahead before mutating anything.
